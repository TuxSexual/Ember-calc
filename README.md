# Ember Calc

Консольный калькулятор риска профессионального выгорания.

Считает примерную вероятность выгорания на основе шести факторов: нагрузка, устойчивость к стрессу, сон, социальная поддержка, позитивные и негативные эмоции.

## Дисклеймер

Это **не диагноз**. Инструмент для самонаблюдения и скрининга. При высоком риске обратитесь к психологу или врачу.

## Клонирование

    git clone https://github.com/TuxStudio-creator/Ember-calc.git
    cd Ember-calc

## Установка

Внешние библиотеки не нужны, только стандартный Python.

Требуется Python 3.10+.

## Запуск

    python main.py
Программа задаст 6 вопросов. Отвечай по шкале от 0 до 10. В конце покажет процент риска, уровень и вклад каждого фактора.

## Тесты

    python tests.py

## Как считается

Каждый фактор имеет **вес** (силу влияния) и **направление**: защитный или риск. Веса взяты из мета-анализов и систематических обзоров.

| Фактор | Вес | Тип | Источник |
|---|---|---|---|
| Нагрузка | 0.678 | риск | систематический обзор, 2025 |
| Устойчивость | 0.595 | защита | мета-анализ, Nature 2026 |
| Проблемы со сном | 0.390 | риск | мета-анализ, Healthcare 2022 |
| Соц. поддержка | 0.300 | защита | мета-анализ, J Appl Psychol |
| Позитивные эмоции | 0.300 | защита | оценка по литературе |
| Негативные эмоции | 0.300 | риск | оценка по литературе |

Итоговый процент, это сумма вкладов всех факторов, нормализованная к 100%.

## Уровни риска

| Процент | Уровень |
|---|---|
| 0–34 | Низкий |
| 35-59| Умеренный |
| 60+ | Высокий |
